# 诉讼立案与程序实务工作台 (Litigation Procedure Workbench)

纯前端、零构建依赖的**中国人民法院立案审查与全流程诉讼程序实务动态 Web 应用**。无需后端服务器或数据库，可直接托管于 **GitHub Pages / Vercel / Cloudflare Pages**，支持桌面双栏工作台、移动端响应式抽屉、深浅色主题切换、URL 专属直达链接分享、交互式诉状起草下载与高清长图导出。

---

## 核心功能特性

### 1. 六大诉讼领域 2,300 项实务问答检索（渐进式分片架构）
- **覆盖全流程**：涵盖**民事诉讼、商事诉讼、刑事诉讼、国家赔偿、行政诉讼、知识产权与竞争**六大领域共 59 章 2,300 个高频立案与程序实务问答。
- **毫秒级加权全文检索**：首屏仅加载轻量目录索引（`catalog.js`），后台无感流式同步 7 个数据分片（`chunks/qa-0..6.js`）；支持按题号（如 `243`、`Q419`）、多关键词组合检索、章节二级联动、上海实务参考标识筛选与关键词高亮，支持快捷键 `⌘K` / `Ctrl+K` 一键唤起搜索。
- **一键分享与高清长图**：每道问答均支持复制专属直达链接、一键复制完整解答+法条、单独复制法条依据，以及生成**自适应高度（绝不截断长文）的 Retina 2x 高清长图（PNG）**。

### 2. 交互式诉讼文书起草与多格式下载
- 内置 **8 类人民法院常用标准诉讼文书交互式起草器**：
  1. `civil_complaint` — **民事起诉状**（《民事诉讼法》第124条）
  2. `civil_appeal` — **民事上诉状**（《民事诉讼法》第172条）
  3. `civil_enforcement` — **强制执行申请书**（《民事诉讼法》第247条）
  4. `criminal_private` — **刑事自诉状**（《刑事诉讼法》第210条）
  5. `criminal_civil` — **刑事附带民事自诉状**（《刑事诉讼法》第101条）
  6. `criminal_appeal` — **刑事上诉状**（《刑事诉讼法》第227条）
  7. `admin_complaint` — **行政起诉状**（《行政诉讼法》第49–50条）
  8. `admin_appeal` — **行政上诉状**（《行政诉讼法》第85条）
- 支持当事人主体一键切换（**自然人 / 法人或非法人组织**）、**本地草稿自动保存**、**一键填入标准示例数据**，右侧同步渲染**仿真 A4 公文纸张预览**。
- **五种导出方式**：
  - **下载 Word (`.doc`)**：内置人民法院公文页边距（A4 `3.7cm / 2.6cm / 3.5cm / 2.8cm`）、二号方正小标宋/中宋标题、三号仿宋正文、固定 `28pt` 行距，兼容 Microsoft Word 与 WPS Office
  - **下载 Markdown (`.md`)**
  - **下载纯文本 (`.txt`，含 UTF-8 BOM)**
  - **一键复制全文**
  - **浏览器纯净 A4 打印 / 另存为 PDF**（自动隐藏导航栏与操作控件）

### 3. 法定诉讼费 / 保全费 / 执行费精确速算器
- 严格按照国务院《诉讼费用交纳办法》第 13–16 条、第 20 条分段累计标准编写，采用**整数“分”运算**消除浮点数精度误差。
- 一次输入标的额，同步测算：**一审普通程序受理费、简易/小额/调解/撤诉减半费、财产保全费（5,000 元封顶）、强制执行申请费、反诉/有独立请求权第三人受理费、督促程序支付令受理费**，附非财产案件定额收费速查表，并支持导出**高清预算单图片**。

### 4. 起诉前 5 步合规自查清单 & 立案期限救济总表
- 交互式勾选核查《民事诉讼法》第 122 条起诉条件、有效仲裁条款与劳动仲裁/行政复议前置程序（勾选进度持久化保存在浏览器 `localStorage`）。
- 汇总 8 类高频程序的法定立案审查期限与救济途径，点击关联题号胶囊即可一键跳转阅读完整法条详解。

## 本地运行与预览

本项目采用原生 HTML5 + CSS3 + ES5/ES6 模块化脚本构建，**无需安装任何 `npm` 依赖，无需打包构建**。在当前目录启动任意静态 HTTP 服务即可完整体验：

```bash
# 方式一：使用系统自带 Python 3（推荐）
python3 -m http.server 8080

# 方式二：使用 Node.js npx
npx serve -l 8080 .
```

启动后在浏览器访问 `http://localhost:8080` 即可。

## 发布到 GitHub 与免费上线 GitHub Pages

项目所有静态资源与分片加载均采用相对路径（`./`）与查询参数路由（`?q=...`），完美兼容 `https://<用户名>.github.io/<仓库名>/` 子路径部署，无需配置伪静态或 404 重定向。

### 三步部署流程

1. **初始化并推送至 GitHub 仓库**（可将本目录作为独立仓库根目录推送）：
   ```bash
   cd web-app
   git init
   git branch -M main
   git add .
   git commit -m "feat: initial release of litigation procedure web workbench"
   git remote add origin https://github.com/<你的用户名>/<你的仓库名>.git
   git push -u origin main
   ```
2. **开启 GitHub Pages 自动部署**：
   - 打开 GitHub 仓库页面 → **Settings** → 左侧菜单 **Pages**
   - 在 **Build and deployment** → **Source** 下拉框中选择 **`GitHub Actions`**
3. 仓库内置的 `.github/workflows/deploy-pages.yml` 工作流会自动运行，约 20 秒后即可通过生成的 `github.io` 网址向任何人分享访问。

> 同样支持一键导入 **Vercel** 或 **Cloudflare Pages**（Framework Preset 选择 `Other`，Build Command 留空，Output Directory 填 `.` 即可零配置上线）。

## URL 专属直达链接参数规范

应用内置双向 URL 状态路由，所有核心功能视图均可通过链接直接定位分享：

| 场景 | URL 参数示例 |
| :--- | :--- |
| 直达指定问答详情（如第 243 题诉前财产保全） | `?q=243` |
| 带关键词与领域筛选的检索结果页 | `?search=诉前保全&part=0` |
| 直达指定文书起草模板（如民事上诉状） | `?tab=draft&tpl=civil_appeal` |
| 直达指定标的额算费结果（如 350 万元） | `?tab=calc&amount=350&unit=10000` |
| 直达起诉前合规自查清单与审查期限表 | `?tab=guide` |
