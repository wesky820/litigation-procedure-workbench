# 人民法院立案审查与诉讼服务核心速查总纲

> **文档定位**：本总纲跨六大诉讼领域（民事、商事、刑事、国家赔偿、行政、知识产权与竞争）提炼人民法院立案审查与全流程程序高频实务规则，聚焦 **12368 诉讼服务导诉、律师/当事人立案前自查、立案庭形式审查与程序分流**。遇到具体细分场景时，请结合条目编号（`Q#`）使用 `scripts/search_qa.py` 或查阅对应的 `references/01..26` 分章模块。

## 二、主管边界与前置程序负面清单（立案必查拦截项）

### 1. 民事起诉七类分流与不予受理情形（《民事诉讼法》第127条，Q421–Q427）
1. **属行政诉讼受案范围**：告知原告提起行政诉讼。
2. **存在有效书面仲裁协议**：告知向仲裁机构申请仲裁；坚持起诉的裁定不予受理（仲裁协议不成立、无效、失效、内容不明无法执行的除外，Q422、Q770–Q795）。
3. **依法应由其他机关处理**：告知向有关机关申请解决（如土地权属确权先行行政处理、人事争议仲裁前置等）。
4. **不属于本院管辖**：告知向有管辖权的人民法院起诉。
5. **一事不再理**：对判决、裁定、调解书已发生法律效力的案件又起诉的，告知申请再审（**但法院准许撤诉的裁定、不予受理/驳回起诉后符合条件再次起诉的除外**，Q421、Q423；赡养/扶养/抚养费因新情况新理由要求增减的作为新案受理，Q426）。
6. **法定期限内不得起诉**：在禁诉期内起诉的不予受理（如女方孕期、分娩后1年内或终止妊娠后6个月内男方不得起诉离婚，法院认为确有必要受理的除外，Q522）。
7. **6个月禁诉期案件**：**判决不准离婚、调解和好、原告撤诉或按撤诉处理的离婚案件**，以及**判决、调解维持收养关系的案件**，没有新情况、新理由，**原告**在 **6个月内** 又起诉的不予受理（被告起诉不受6个月限制，Q424、Q523）。
8. **易混提示——超过诉讼时效仍应立案**：当事人超过诉讼时效起诉的，**法院必须受理，不得在立案阶段以超时效为由裁定不予受理**；审理中对方提出时效抗辩查明成立的，判决驳回诉讼请求（Q427）。

### 2. 劳动人事争议仲裁前置规则（Q466–Q517、Q818–Q821）
- **一般规则**：劳动争议须先申请劳动争议仲裁；对仲裁裁决不服或仲裁委逾期未作出受理决定/裁决（出具逾期未审结证明）、决定不予受理的，收到裁决书/不予受理通知书之日起 **15日内** 向法院起诉。
- **例外直诉情形**：劳动者以用人单位的**工资欠条**为证据直接向法院起诉，诉讼请求不涉及劳动关系其他争议的，视为拖欠劳动报酬争议，按照普通民事纠纷直接受理（Q471）。
- **一裁终局双轨救济**：追索劳动报酬、工伤医疗费、经济补偿或赔偿金（不超过当地月最低工资标准12个月金额）及执行国家劳动标准争议属一裁终局：**劳动者不服可在15日内起诉；用人单位不得起诉，但可在30日内向仲裁委所在地中级法院申请撤销裁决**（Q506–Q515）。

### 3. 行政诉讼排除事项与 2023 新《行政复议法》复议前置清单（Q2042–Q2049、Q2085–Q2086、Q2112）
- **法定不予受理排除项**：国防外交国家行为；行政法规、规章或行政机关制定发布的具有普遍约束力的决定、命令（规章以下规范性文件可在诉具体行政行为时申请**一并附带审查**，不可单独起诉，Q2109）；行政机关内部奖惩任免决定；法律规定由行政机关最终裁决的行为；公安国安依刑事诉讼法授权实施的侦查行为；调解行为及法定仲裁行为；不产生实际影响的行政指导行为；驳回申诉的重复处理行为等（Q2043）。
- **必须先行申请行政复议的五大前置情形（《行政复议法》2023修订第23条，Q2086）**：
  1. 对**当场作出**的行政处罚决定不服；
  2. 对行政机关作出的侵犯其已经依法取得的**自然资源的所有权或者使用权**的决定不服；
  3. 认为行政机关存在**未履行法定职责**情形（须先申请复议，注意区别于旧法自选模式）；
  4. 申请**政府信息公开**，行政机关**不予公开**（另：认为不履行主动公开义务的，须先向行政机关申请获取相关政府信息，Q2112）；
  5. 法律、行政法规规定应当先申请行政复议的其他情形（如纳税争议等）。

### 4. 刑事自诉与拒执罪自诉立案条件（Q1722、Q1825–Q1835）
- **三类刑事自诉案件**：（1）告诉才处理的案件（侮辱、诽谤案［严重危害社会秩序和国家利益除外］、暴力干涉婚姻自由案、虐待案、侵占案）；（2）被害人有证据证明的轻微刑事案件（故意伤害轻伤案、非法侵入住宅案、侵犯通信自由案、重婚案、遗弃案、生产销售伪劣商品案［严重危害社会秩序和国家利益除外］、侵犯知识产权案［同前］、刑法分则第四/五章可能判处3年以下有期徒刑案件）；（3）公诉转自诉案件（被害人有证据证明对被告人侵犯自己人身、财产权利的行为应当依法追究刑事责任，而公安机关或检察院不予追究被告人刑事责任的案件）。
- **拒不执行判决、裁定罪自诉双要件（Q1826）**：（1）负有执行义务的人拒不执行判决、裁定，侵犯申请执行人人身、财产权利，应依法追究刑责；（2）**申请执行人曾经提出控告，而公安机关或人民检察院对负有执行义务的人不予追究刑事责任**。

### 2. 高频地域管辖、专属管辖与协议管辖要点
- **“原告就被告”四大法定例外（由原告住所地管辖，Q11）**：（1）对不在中国领域内居住的人提起的有关身份关系的诉讼；（2）对下落不明或者宣告失踪的人提起的有关身份关系的诉讼；（3）对被采取强制性教育措施的人提起的诉讼；（4）对被监禁的人提起的诉讼。
- **合同履行地确定三步规则（Q25–Q29）**：
  1. 有约定且约定了明确履行地的 → 按**约定履行地**（注意：仅约定合同签订地不等于约定履行地）；
  2. 未约定或约定不明 → 争议标的为**给付货币**的，**接收货币一方所在地**为合同履行地；**交付不动产**的，不动产所在地；**其他标的**，**履行义务一方所在地**为合同履行地；即时结清合同以交易行为地为履行地；
  3. **网购合同特殊规则**：以信息网络方式订立的买卖合同，通过信息网络交付标的的以**买受人住所地**为履行地；通过其他方式交付标的（如快递物流发货）的以**收货地**为合同履行地（合同另有约定从约定，Q29）。
- **专属管辖（不得协议变更，违反则依职权移送，Q53、Q1334）**：
  - 国内专属：（1）**不动产纠纷**（含建设工程施工合同、农村土地承包、房屋租赁、不动产确权分割等）→ 不动产所在地；（2）**港口作业纠纷** → 港口所在地；（3）**继承遗产纠纷** → 被继承人死亡时住所地或主要遗产所在地。
  - 涉外新增专属（《民事诉讼法》2023修正第279条，Q1334）：除上述外，**在中国领域内设立的法人或其他组织的设立、解散、清算及决议效力纠纷**，以及**在中国领域内审查授予的知识产权有效性有关纠纷**，由中国法院专属管辖。
- **协议管辖有效五要件（Q49–Q52）**：（1）仅限合同或其他财产权益纠纷；（2）采用**书面形式**（含电子数据交换、电子邮件等）；（3）选择**被告住所地、合同履行地、合同签订地、原告住所地、标的物所在地**等与争议有实际联系地点的法院（涉外协议选择中国法院的可选择与争议有实际联系地点或径行约定中国法院管辖）；（4）选择明确唯一（两个以上协议管辖法院不明且无法补充达成的适用法定管辖）；（5）**不得违反级别管辖和专属管辖**。

## 五、近年核心新修法律与诉讼程序变动要点（现行有效口径）

在解答程序问题时，务必以现行有效新规为准，切勿沿用旧法过时口径：

1. **《民事诉讼法》（2023修正）重大变化**：
   - **裁判文书全面开放电子送达**：经受送达人同意，**判决书、裁定书、调解书均可采用电子方式送达**；受送达人提出需要纸质文书的，法院应当提供（Q220、Q224；旧法曾禁止裁判文书电子送达）。
   - **涉外公告送达大幅缩短**：国内公告送达为 **30日**，**涉外公告送达由原来的 3个月 缩短为 60日**（Q231、Q1338）。
   - **海牙《取消外国公文书认证要求的公约》落地**：缔约国出具的域外身份证明与授权委托书，经所在国公证并办理 **附加证明书（Apostille）** 即可，无需再办理我国驻该国使领馆领事认证（Q1322、Q1323）。
   - **涉外管辖扩张与平行诉讼、不方便法院协调**：扩充涉外管辖连接点与两类涉外专属管辖（境内法人设立解散清算决议、境内知产有效性），明确平行诉讼受理、中止与外国裁判承认规则（Q1333–Q1337）。
   - **特别程序新增“指定遗产管理人案件”**：对担任遗产管理人有争议向法院申请指定的，由被继承人死亡时住所地或主要遗产所在地基层法院适用特别程序审理（Q952–Q957）。
2. **《公司法》（2023修订，2024年7月1日施行）诉讼程序更新（Q1507–Q1586）**：
   - 法定代表人辞任后公司应在 **30日内** 确定新法定代表人，逾期可诉请变更涤除（Q1508）；
   - 新增**公司决议不成立之诉**（与无效、可撤销并列为决议三分法，撤销除斥期为知道或应当知道之日起60日，最长不超过自决议作出之日起1年，Q1521–Q1527）；
   - 董事会负有核查并书面催缴出资义务，新增股东失权制度与非破产情形下出资加速到期规则（Q1537–Q1544）；
   - 股东知情权扩展至查阅**会计凭证**及**全资子公司**相关材料（Q1516–Q1520）；新增双重股东代表诉讼与横向法人人格否认程序规则。
3. **《行政复议法》（2023修订）复议前置扩容（Q2086）**：当场行政处罚、侵犯已依法取得的自然资源权属决定、行政不作为（未履行法定职责）、政府信息公开不予公开均须**复议前置**。
4. **2024年最新司法解释吸收**：反垄断民事诉讼司法解释（法释〔2024〕6号，仲裁条款不能排除垄断民事诉讼管辖，Q2297–Q2300）、拒执罪司法解释（法释〔2024〕13号，Q1722）、认可和执行台湾地区法院民事判决规定（2024修正，Q1465–Q1477）。
